# Conceito Principal

O cliente nunca procura um laudo.

Ele procura resolver um problema.

Exemplos:

• Meu prédio apareceu uma trinca.

• Preciso tirar AVCB.

• Meu imóvel está com infiltração.

• Preciso vender um imóvel.

• A prefeitura exigiu um laudo.

• Preciso de um documento para um processo.

Toda comunicação deve partir desse princípio.
